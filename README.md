# Astro Tax

Личная налоговая консоль (США) в стиле Astro Routine / Nomad: штат, режим работы,
счета, доходы, списания, квартальные платежи 1040-ES — сколько и когда платить.

Статический сайт без сборки (ES-модули) → GitHub Pages (публикуется прямо из ветки `main`). Данные — Firebase
Firestore с офлайн-кэшем. Регистрация — вход через Google; у каждого пользователя
свои данные, чужие не видны никому.

## Как устроено

| Файл | Что внутри |
|------|------------|
| `js/tax/rules.js` | федеральные ставки 2026 (Rev. Proc. 2025-32), категории списаний |
| `js/tax/states.js` | штаты: без налога / плоская ставка / ориентир для прогрессивных |
| `js/tax/engine.js` | расчёт за год: SE tax, AGI, стандартный вычет, QBI, подоходный, штат |
| `js/tax/schedule.js` | календарь 1040-ES (переносы на рабочий день), кварталы, safe harbor, annualized method |
| `js/tax/sync.js` | **часы налогов** — как часы корабля в Astro Routine |
| `js/store.js` | Firestore (`users/{uid}/…`) или localStorage, если Firebase не настроен |
| `firestore.rules` | каждый аккаунт видит только `users/{свой uid}` |

### Синхронизация (часы налогов)

В профиле лежит `syncedAt`. При каждом входе, изменении данных, возврате на
вкладку и раз в 15 минут движок смотрит на год «на сейчас» и решает, какие
события должны существовать: платёж скоро, платёж просрочен (с оценкой пени),
скоро декларация. `EventSync` пишет их идемпотентно: нет — создаёт, открыто и
изменилось — обновляет, больше не нужно — закрывает, закрыто/прочитано — не
трогает. Поэтому синк можно гонять на любом устройстве — журнал сходится.

Сами данные синхронизируются Firestore между устройствами; офлайн всё работает
из локального кэша и догоняет облако при появлении сети (индикатор в шапке).

## Настройка (один раз)

1. **Firebase** — [console.firebase.google.com](https://console.firebase.google.com) → новый проект (например `astro-tax`).
   - Build → Authentication → Sign-in method → **Google** → Enable.
   - Build → Firestore Database → Create database (production mode).
   - Project settings → Your apps → **Web** → скопировать `firebaseConfig` в `js/config.js`.
2. **Правила доступа:**
   ```bash
   firebase login
   firebase use --add        # выбрать проект
   firebase deploy --only firestore:rules
   ```
3. **GitHub Pages** уже включён: Settings → Pages → Deploy from branch `main` / root. Каждый push в `main` = новая версия сайта.
4. **Домен для входа:** Firebase → Authentication → Settings → Authorized domains → добавить `<user>.github.io`.

### Кто что видит

- Зарегистрироваться может любой: первый вход через Google создаёт аккаунт.
- `firestore.rules` пускает к `users/{uid}/…` только того, чей это `uid`.
  Всё остальное закрыто — чужие данные не прочитать и не изменить.
- `firebaseConfig` в коде публичен по задумке Firebase — это не секрет; замок — правила.

## Локально

```bash
npm test                 # движок налогов
npm run serve            # http://localhost:5173
```

Пока `apiKey` в `js/config.js` пустой, приложение работает в локальном режиме
(данные только в этом браузере).

## Ограничения

Это оценка, не налоговая консультация. Штаты считаются одной ставкой от
федерального AGI (без вычетов штата) — для прогрессивных штатов впиши свою
эффективную ставку в профиле. QBI считается консервативно (выше порога — как
SSTB без W-2 зарплат). Новые ставки года добавляются в `js/tax/rules.js`.
